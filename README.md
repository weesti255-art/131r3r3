# MailControl

Локальная почтовая рассылка через Почту Mail для одного оператора (MVP-1).

- Инструкция запуска и состояние этапа M1: [mailcontrol/README.md](mailcontrol/README.md).
- План, границы и правила MVP-1: [AGENTS.md](AGENTS.md).
- Текущее состояние и журнал проверок: [PROGRESS.md](PROGRESS.md).

Код приложения находится в `mailcontrol/`. Команды `START-DEMO.cmd`,
`START-EMPTY.cmd` и `STOP.cmd` в корне запускают тот же Docker Compose,
что и одноимённые файлы внутри `mailcontrol/`.
