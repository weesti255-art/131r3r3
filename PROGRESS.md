- `mailcontrol/README.md`, `START-DEMO.cmd`, `START-EMPTY.cmd`, `STOP.cmd`,

- `mailcontrol/scripts/` — воспроизводимый native Preview, проверка Compose и ZIP.

## Ограничения и решения для следующего агента

- Пользователь разрешил только M1 и попросил скачиваемый архив. Не продолжать M2
  автоматически и не выдавать макеты импорта/отправки за работающие функции.
- Внешние инструкции подтверждают SMTP Mail `smtp.mail.ru:465` и отдельный пароль
  приложения. Совместимость конкретных реальных аккаунтов пока не проверена.
- Пароли и реальные адреса для контрольной отправки не запрашивать в открытом
  журнале. На M4 использовать безопасно предоставленные доступы и разрешённых получателей.
- Windows 10/11 требует рабочей совместимой установки Docker/WSL и виртуализации.
  Проверка Linux-контейнеров не доказывает работоспособность на Windows.
- Из репозитория не установлены зависимости Hydra и не запускались её сборка
  или приложение. Зависимости MailControl устанавливаются внутри `mailcontrol/`.
- Первоначальный визуальный референс содержит прокси, графики и недоказанную
  «успешную доставку». Эти элементы сознательно не включены в обязательный MVP.
- Импорт в M1 не принимает реальные пароли. Таблица аккаунтов содержит только
  подписанные демонстрационные примеры; шифрование и реальный импорт — M2.
- Preview использует отдельный локальный PostgreSQL на 55432; данные и конфигурация
  в игнорируемой `.local/`. Приложение работает ролью `mailcontrol_app` без
  superuser/createdb/createrole/replication. Setup и тесты имеют отдельный доступ.
- Effective setup/run проекта указывают на `mailcontrol/scripts/setup-preview.sh`
  и `preview.sh`. Команда `sandbox_control setup` дважды отказала при состоянии
  ready; платформенный сбой сообщён. Тот же сохранённый setup выполнен через shell.
  Сам браузерный сервер управляется только managed Preview.

подготовлен MVP без прокси, с ранней проверкой интерфейса и последующей реальной

### 2026-09-22 — M1: браузерный интерфейс и сохранение

**Статус:** M1 реализован и проверен. M2–M5 не начинались. Подготовлен отдельный
`MailControl-M1.zip`, а не архив всей Hydra.

**Что сделано:**

- Самостоятельный проект `mailcontrol/`: Node.js 24 LTS, React/TypeScript/Vite,
  Fastify и PostgreSQL 16. Версии npm-пакетов закреплены отдельным lock-файлом;
  шрифты поставляются локально, CDN не нужен. Hydra не изменялась.
- Четыре русскоязычных экрана по направлению образца: главная, аккаунты,
  рассылки, события. Реальные счётчики сохранённых записей, поиск, фильтры,
  страницы таблиц, пустые состояния, отображение недоступности API.
- Форма группы: название, цвет, положительные целые значения лимита новой
  пачки. У демо-аккаунтов свои сохранённые значения, не счётчик группы.
- Четыре шага мастера: параметры, пока недоступные получатели, обычный текст,
  проверка и сохранение. Есть повторное открытие/редактирование черновика,
  защита несохранённого ввода, блокировка формы на время сохранения, ограниченный
  тайм-аут, диалоги с ловушкой/возвратом фокуса и неактивным фоном.
- API и SQL-транзакции сохраняют данные и события вместе. Повтор запроса
  создания не дублирует группу/черновик; номер редакции защищает от незаметного
  затирания правок в другом окне. Старый ответ поиска не подменяет новый фильтр.
- Первая миграция применяется атомарно под блокировкой; изменение уже
  применённого файла отвергается по контрольной сумме. Маркер `demo/local`
  защищает БД от смешивания режимов; демонабор создаётся ровно один раз.
- Настоящего импорта, паролей, расчёта квоты, получателей, очереди и отправителя
  нет. Недоступные действия объясняют этап M2/M3 и не сообщают фиктивный успех.
  В коде нет SMTP-адаптера и сетевого подключения к Mail.
- Host/Origin и JSON проверяются на сервере, открытый CORS не включён,
  сообщения об ошибках не содержат тел запросов, строк подключения и stack trace.
- Подготовлены Dockerfile, Compose с постоянными раздельными томами и только
  `127.0.0.1:3000` снаружи, Windows-команды запуска/остановки и инструкция.
  `STOP.cmd` не удаляет данные; генерация пароля БД локальная.

- `npm test`: 8/8 unit. `npm run test:integration`: 14/14 на реально созданных
